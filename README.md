# CCAF 2026 — Preparation Class

Claude Certified Architect Foundations course materials.

## Quick Start
- **Site**: `class/site/index.html` — open in browser for the full syllabus
- **Interactive Tutor**: `class/site/lesson-d1.html` through `class/site/lesson-d5.html`
- **API**: Deploy on Vercel — `vercel --prod`

## Structure
- `class/lessons/d1.json` through `d5.json` — lesson data for each domain
- `class/banks/d1-questions.md` through `d5-questions.md` — question banks
- `class/domains/` — domain reference notes
- `class/site/` — full web interface (HTML, CSS, JS)
- `video_transcript_ldqOnljDINc.json` — YouTube transcript (D1)
- `build_lesson_d1.py` — lesson data builder
